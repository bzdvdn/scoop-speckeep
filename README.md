# Scoop bucket for speckeep

[Scoop](https://scoop.sh) bucket for [`speckeep`](https://github.com/bzdvdn/speckeep) — strict, lightweight spec-driven development for coding agents.

```powershell
scoop bucket add speckeep https://github.com/bzdvdn/scoop-speckeep
scoop install speckeep
```
